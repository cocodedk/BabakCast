دانلود. خلاصه‌سازی. اشتراک‌گذاری.

BabakCast به شما امکان می‌دهد ویدیوهای یوتیوب، X (توییتر)، اینستاگرام و لینکدین را دانلود کنید، متن توییت را کپی یا به اشتراک بگذارید، و متن زیرنویس ویدیوهای یوتیوب را با هوش مصنوعی خودتان خلاصه کنید. بدون حساب کاربری، بدون آمارگیری، بدون ردیابی.

دانلود برنامهٔ اندروید مشاهده در GitHub

چه کار می‌کند

دانلود از یوتیوب، X، اینستاگرام و لینکدین

پیوند یک ویدیو از یوتیوب، X (توییتر)، اینستاگرام یا لینکدین را بچسبانید و فایل ویدیویی یا صوتی قابل اشتراک‌گذاری بگیرید. صدا را یکجا نگه دارید یا به بخش‌هایی با اندازهٔ دلخواه (پیش‌فرض ۱۶ مگابایت) تقسیم کنید. هر بخش با «Part n of N» برچسب می‌خورد تا گیرنده بتواند ترتیب درست را تشخیص دهد.

دانلود رسانه‌های پست X (توییتر)

عکس‌ها، ویدیوها و GIFهای یک پست X (توییتر) را با یک ضربه دانلود کنید و با هم به اشتراک بگذارید. از پست‌هایی که هم عکس و هم ویدیو دارند، فعلاً فقط عکس‌ها ذخیره می‌شوند.

کپی و اشتراک‌گذاری متن توییت

یک لینک X (توییتر) بچسبانید. برای کپی متن توییت در کلیپ‌بورد Copy Text را بزنید و برای باز کردن پنجرهٔ اشتراک‌گذاری اندروید Share Text را بزنید. نیازی به دانلود رسانه نیست.

متن به خلاصه

برای یک ویدیوی یوتیوب، BabakCast زیرنویس‌ها را می‌گیرد و از مدل هوش مصنوعی شما خلاصه‌ای به‌شکل فهرست نکات می‌خواهد. یکی از Short، Medium یا Long را انتخاب کنید.

هوش مصنوعی خودتان

کلید API خودتان (کدی که ارائه‌دهندهٔ هوش مصنوعی به شما می‌دهد) و یک مدل را در Settings وارد کنید. در این نسخه OpenAI و OpenRouter کار می‌کنند. Azure OpenAI، Anthropic و Gemini در فهرست هستند، اما هنوز کامل نشده‌اند.

فایل‌های شما روی گوشی می‌مانند

دانلود، تقسیم و برش روی گوشی شما انجام می‌شود. برای خلاصه و ترجمه، متن به ارائه‌دهندهٔ هوش مصنوعی‌ای که تنظیم کرده‌اید فرستاده می‌شود. کلیدهای API روی گوشی شما رمزگذاری‌شده ذخیره می‌شوند.

ترجمه فارسی هنگام اشتراک‌گذاری

Translate to Persian را روشن کنید تا BabakCast زیر متن اصلی، ترجمهٔ فارسیِ ساخته‌شده با هوش مصنوعی را اضافه کند: برای متن توییت، خلاصه‌ها و متنی که همراه صدا و رسانهٔ X فرستاده می‌شود. دانلود ویدیو و اشتراک‌گذاری از تب Downloads ترجمه نمی‌شوند.

BabakCast ابزاری برای استفادهٔ شخصی است. بدون کلید API از پیش‌تعیین‌شده، بدون تبلیغات، بدون ردیابی استفاده و بدون حساب کاربری. ارائه‌دهندهٔ هوش مصنوعی را خودتان انتخاب می‌کنید و خودتان تصمیم می‌گیرید چه چیزی برایش فرستاده شود.

ارائه‌دهندگان هوش مصنوعی

ارائه‌دهنده را در Settings تنظیم کنید. کلید API شما رمزگذاری‌شده روی گوشی‌تان می‌ماند. در این نسخه OpenAI و OpenRouter کار می‌کنند. سه مورد دیگر در فهرست هستند، اما هنوز کامل نشده‌اند.
