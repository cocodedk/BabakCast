Android · No accounts · No tracking

Download. Summarize. Share.

BabakCast downloads videos from YouTube, X (Twitter), Instagram and LinkedIn, copies tweet text, and turns YouTube transcripts (the written text of what is said) into summaries with your own AI provider. No accounts, no analytics, no tracking.

Download Android app View GitHub

What it does

YouTube, X, Instagram & LinkedIn download

Paste a link from YouTube, X (Twitter), Instagram or LinkedIn and get a video or audio file you can share. Keep audio in one piece, or split it into parts of a size you choose (16 MB by default). Each part is tagged “Part n of N”, so recipients can tell the intended order.

X (Twitter) post media

Download the photos, videos and GIFs from an X (Twitter) post with one tap, then share them together. A post that has both photos and videos currently saves the photos only.

Tweet text copy & share

Paste an X (Twitter) link and tap Copy Text to copy the tweet to your clipboard, or Share Text to open the share sheet. No media download is needed.

Transcript to summary

For a YouTube video, BabakCast gets the captions and asks your AI model for a bullet-point summary. Choose Short, Medium or Long.

Bring your own AI

Add your own API key (the access code your AI provider gives you) and a model in Settings. OpenAI and OpenRouter work in this version. Azure OpenAI, Anthropic and Gemini are listed but not finished yet.

Your files stay on your phone

Downloading, splitting and cutting run on your phone. Summaries and translations send text to the AI provider you set up. Your API keys are stored encrypted on your phone.

Persian translation on share

Turn on Translate to Persian and BabakCast adds an AI-generated Persian translation below the original in tweet text, summaries, and the text that goes with audio and X media. Video downloads and shares from the Downloads tab are not translated.

BabakCast is a tool for personal use. It comes with no API keys, no ads, no usage tracking and no accounts. You choose your AI provider, and you decide what you send to it.

AI providers

Install on Android

  • Coming to F-Droid

  • Download the Android installation file (APK) from GitHub
  • Add the app to Obtainium, an app that keeps it up to date
1

Download the app file

Use the download link above, or get it from GitHub Releases. The file is called an APK, which is the installation file for an Android app.

2

Allow installation

When Android asks, allow "Install from unknown sources" for your browser or file manager.

3

Install the app

Open the downloaded .apk file and tap "Install".

4

Set up an AI provider (optional)

Only needed for summaries and translations. Open Settings, tap OpenAI or OpenRouter under AI Providers, enter your API key, select a model and tap Save and use this provider. Downloading videos works without this step.
